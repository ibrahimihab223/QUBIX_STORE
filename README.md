# QUBIX

متجر إلكتروني بصفحات HTML مستقلة، وCSS، وJavaScript، مع API بـPHP وقاعدة بيانات MySQL. تُحفظ الحسابات والمنتجات والطلبات ورسائل التواصل وتقييمات المشترين في MySQL.

QUBIX هو الاسم التجاري المقترح للمتجر؛ لم يتم التحقق من توفره أو تسجيله كعلامة تجارية.

## تشغيل المتجر على XAMPP

1. شغّل Apache وMySQL من لوحة تحكم XAMPP.
2. افتح `http://localhost/phpmyadmin`.
3. عند التثبيت لأول مرة، استورد [schema.sql](./backend/schema.sql).
4. عند وجود قاعدة `nexashop` سابقة، استورد [migrate_real_store.sql](./backend/migrate_real_store.sql) مرة واحدة لإضافة تفاصيل التوصيل وجداول التقييمات والرسائل.
5. راجع [config.php](./backend/config.php) واضبط بيانات اتصال MySQL؛ أسماء متغيرات البيئة الجديدة تبدأ بـ`QUBIX_DB_`، مع استمرار دعم `NEXASHOP_DB_` للتوافق.
6. افتح `http://localhost/my%20project/nexashop-fullstack/frontend/` أو استخدم مسار مجلدك الفعلي. لا تفتح ملفات HTML باستخدام `file://`؛ يلزم Apache وPHP للاتصال بقاعدة البيانات.

يتطلب PHP 8.1 أو أحدث مع PDO وPDO MySQL. اسم قاعدة البيانات الافتراضي `nexashop` اسم تقني قديم لتجنب نقل أو حذف قاعدة بياناتك عند تغيير العلامة التجارية؛ يمكن تغييره عبر `QUBIX_DB_NAME`.

## بيانات المتجر

- الحسابات وكلمات المرور المشفّرة، الطلبات، تفاصيل التوصيل، ورسائل التواصل محفوظة في MySQL.
- الأسعار الحالية تُقرأ من جدول `products`، وتُراجع مجددًا من قاعدة البيانات عند إنشاء الطلب.
- ينشئ `schema.sql` كتالوجًا فارغًا بدل عرض منتجات أو أسعار تجريبية. أضف مخزونك الفعلي إلى جدول `products` قبل استقبال العملاء؛ لا توجد خدمة خارجية تتحقق من توفر المنتجات أو أسعار السوق.
- ترحيل قاعدة سابقة لا يحذف المنتجات الموجودة حفاظًا على بياناتك؛ راجع الكتالوج القديم واستبدل أي سجلات تجريبية يدويًا قبل نشر المتجر.
- السلة والمفضلة وصورة الملف الشخصي محفوظة محليًا في المتصفح، وليست في حساب المستخدم على الخادم.
- لا يوجد دفع إلكتروني أو كوبونات خصم. يُسجّل الطلب بحالة «قيد المراجعة» دون تحصيل أموال.
- يستطيع العميل كتابة تقييم واحد للمنتج بعد اكتمال طلب يحتوي عليه. يحتفظ الموقع بالتقييمات في قاعدة البيانات ويحسب المتوسط والعدد منها.
- رسائل صفحة التواصل تُحفظ في قاعدة البيانات وتظهر للمديرين والموظفين المخولين.

## لوحة الإدارة

أنشئ أول مدير من PowerShell:

```powershell
& "C:\xampp\php\php.exe" "C:\xampp\htdocs\my project\nexashop-fullstack\backend\create_admin.php"
```

يعرض الأمر كلمة مرور عشوائية مرة واحدة؛ احتفظ بها بأمان. لا يوجد حساب افتراضي. لوحة الإدارة متاحة للأدوار `manager` و`admin` وتعرض بيانات MySQL وتسمح بتحديث حالة الطلبات بعد تنفيذها فعليًا.

## الحسابات

- التسجيل للعملاء فقط؛ الموظفون لا ينشئون حسابات من صفحة التسجيل.
- اسم المستخدم من 3 إلى 32 حرفًا إنجليزيًا أو رقمًا أو نقطة أو شرطة سفلية.
- يلزم اسم وبريد إلكتروني صحيح غير مستخدمين من قبل.
- كلمة المرور من 8 إلى 72 حرفًا، وتحتوي حرفًا إنجليزيًا ورقمًا على الأقل؛ يجب تأكيدها عند التسجيل.
- الدخول يقبل اسم المستخدم أو البريد الإلكتروني.
